QUICK REFERENCE

Command syntax guide.

Not sure what to enter? Here's a quick breakdown.

⌘
[user]

Select a Discord member.

Example: @Emmy
[amount]

Enter a number or currency amount.

Example: 500
[channel]

Select a server text channel.

Example: #general
[role]

Select a server role.

Example: @Members
[item]

Enter the name of an item.

Example: Cat Tree
[text]

Enter your own custom text.

Example: Welcome to the server!
[duration]

Specify a length of time.

Example: 10m, 2h, 1d
[reason]

Explain why an action is being taken.

Example: Breaking server rules
✳ Square brackets indicate information you need to provide. They are not typed as part of the command itself.
